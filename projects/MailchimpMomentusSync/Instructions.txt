KALLMAN MAILCHIMP TO MOMENTUS SYNC
=================================
Release 3.3.0

NORMAL USE

1. Double-click "Run Mailchimp Sync.cmd".
2. In the first queue row, click the file cell and select the raw Mailchimp CSV.
3. Type the CAMPAIGN name.
   Example: SOFEX 2027 Last Call
4. Click the date cell and select the CAMPAIGN SENT DATE shown in Mailchimp.
5. Enter the four-digit Event ID.
6. Select the CAMPAIGN TYPE.
   This automatically sets the Click and Open activity codes.
7. Select the SALESPERSON.
   This automatically sets the salesperson account code.
8. Review the row's engaged campaign recipients and clicked activity/note count.
9. Click "+ Add another file" and repeat for any additional campaign files.
10. Click "Run Queue", review every row, and confirm.

Files run one at a time in the order shown. Each file has its own audit folder.
If a file fails, later rows do not start.

IMPORTANT DIFFERENCE

CAMPAIGN = the name you want written on the exhibitor engagement note.
CAMPAIGN SENT DATE = the date the campaign was sent from Mailchimp.
CAMPAIGN TYPE = the dropdown used only to choose the Momentus activity codes.

MOMENTUS WORDING

The exhibitor note heading will look like:
  SOFEX 2027 Last Call - Sent on August 21, 2026

Activity subjects use that same friendly heading instead of an internal code.
Activity text shows the campaign, opened count, clicked count, and sent date.

RAW MAILCHIMP CSV

The CSV must contain these headers. Their order does not matter:

  email
  first_name
  last_name
  opens
  clicks
  account_code

Extra Mailchimp columns are ignored.
Only records that opened or clicked, have an Account Code, and resolve to a
Momentus contact are added to the new Momentus campaign. No-interaction records
are ignored. Engaged contacts with no Primary Account remain in the campaign
but skip organization-dependent work. Account codes not found in Momentus are
skipped and listed in the audit CSV.
Only records with Clicks greater than zero go through the existing exhibitor,
activity, and note workflow.

MOMENTUS CAMPAIGN

The campaign is created LAST and includes every engaged contact. Exhibitor
organizations are not campaign details, so the OPE and CLI totals represent
people rather than people plus companies.

Campaign detail statuses:
  OPE  Opened               Opens greater than 0 and Clicks 0
  CLI  Opened and Clicked   Clicks greater than 0

The campaign uses the selected Event ID, salesperson as Coordinator, total
emails sent, rounded response percentage, sent date as Start Date, and today's
date as End Date. Emails Sent and response percentage use the full Mailchimp
send population, including ignored no-interaction rows. Group is left blank.

Followed Up is not assigned automatically. Staff can set it later in Momentus.

If an exact campaign already exists after a partial run, the app loads every
existing detail page and adds only missing valid accounts. A stale organization
account is skipped and identified in the output and audit.

An engaged contact with no Primary Account is still added to the campaign. The
contact is skipped only for exhibitor, activity, and note work that requires an
organization.

UPDATE LISTS LATER

Click "Manage Lists" in the app.
You can add, edit, or remove Campaign Types, activity codes, Salespeople, and
salesperson account codes.

Saved user changes are stored at:
  %LOCALAPPDATA%\Kallman\MailchimpMomentusSync\ImportMappings.json

IMPORTANT

- This is a live Momentus update.
- Do not rerun a completed file.
- Review the audit if a run reports a real error.
